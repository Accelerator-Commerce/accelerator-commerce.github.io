Got a lot of audio files to add at once? Use Library > Bulk Upload instead of adding tracks one at a time.

  1. Drag in as many files as you need (or select them from your computer).
  2. Fill in details for each file — like its name or description — before saving.
  3. Save, and all the tracks land in your Library, ready to assign to pages.
Free plan: up to 3 files per batch.
Starter and Pro plans: no practical batch limit.
