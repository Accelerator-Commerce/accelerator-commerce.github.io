Can You Still Auto-Apply a Shopify Gift Card Code From a Link? What Changed in 2022

Short answer: No. A discount-parameter trick once let a gift card code be applied automatically at checkout from a link — useful for gifting emails or "redeem now" landing pages. It broke when Shopify changed how discount parameters work in October 2022, and the underlying parameter was later dropped entirely. A customer clicking a gift link today still has to manually paste the code at checkout.

What used to work

Before the change, a merchant could build a link that passed a gift card's code as a discount parameter in the URL, so that clicking the link carried the customer straight to checkout with the code already applied — no manual entry needed. That made a gifting flow feel seamless: a customer receives a gift email, clicks a "redeem now" button, and lands at checkout with the card's value already subtracted from their total.

What changed, and when

A Shopify Community thread, Problem with the auto-apply discount param change and gift cards, documents merchants running into this directly: Shopify changed how the discount parameter behaves at checkout in October 2022, breaking the auto-apply trick for gift cards. There was a brief period where a patched workaround still functioned, but the underlying parameter needed for it was later removed for good. The capability isn't coming back through that mechanism — it's a platform-level change, not a bug waiting to be fixed.

Why this still matters even though it's a few years old

It's easy to assume an old platform change is no longer relevant, but the gap it left behind is still live today: any merchant building a gifting email, a promotional landing page, or a "send this as a gift" flow that assumes the code will auto-apply is setting up a customer for a confusing checkout moment. If the expectation was set that clicking a link means the discount is already handled, and instead the customer lands at a normal checkout with no code applied, that's a real point of friction and potential abandoned carts — not a cosmetic issue.

What merchants can actually do instead

  • Set the right expectation in the gifting message itself. Rather than implying the code will apply automatically, tell the recipient plainly that they'll need to enter the code at checkout — and make the code easy to copy directly from the email or landing page.
  • Make the code visually prominent and copyable. A code buried in body text is easy to miss; a clearly formatted, tap-to-copy code reduces the friction of manual entry considerably.
  • Point customers to a balance checker before they're surprised at checkout. If a recipient wants to confirm a card's value before shopping, a visible, accurate balance lookup — the same thing covered in our guide to showing gift card balance on Shopify — sets a clear, trustworthy expectation up front rather than leaving them guessing.

A narrower problem than it first sounds

It's worth being precise about what this is and isn't. This is specifically about automatically applying a gift card code at checkout from a link — not about checking a card's balance, which is a separate action that was never affected by this change. A customer can still look up a gift card's remaining value at any time; they just can't have the code itself pre-filled into checkout from a URL anymore.

Frequently asked questions

Can a gift card code still be pre-applied at checkout from a link?

No. The discount-parameter mechanism that made this possible changed in October 2022 and the underlying parameter was later removed. Customers now need to manually enter the code at checkout.

Does this affect checking a gift card's balance?

No — balance checking is unaffected and works the same way as always. This change only affects automatically applying the code itself at checkout.

Is there a workaround to restore auto-apply for gift cards?

Not through the original mechanism — Shopify removed the underlying parameter it relied on. The practical fix is setting clear expectations in gifting messages that the code needs to be entered manually, and making that code easy to find and copy.
