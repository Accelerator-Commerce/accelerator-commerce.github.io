# Accelerator Commerce website

Lightweight static website concept for Accelerator Commerce.

Structure:
- `/` homepage
- `/apps/` app directory
- `/apps/listen-now.html`
- `/apps/gift-check-pro.html`
- `/apps/fresh-cal.html`
- `/docs/` documentation hub
- `/docs/<app>/` documentation landing pages
- `/support.html`
- `/about.html`
- `/privacy.html`

The implementation is plain HTML/CSS/JS with no framework and no runtime dependencies.

Before production:
1. Replace the placeholder privacy policy with the approved policy.
2. Replace/add detailed app documentation based on the actual in-app flows.
3. Add approved app screenshots/logos.
4. Verify Shopify App Store URLs and any pricing claims.
5. Configure hosting so `/apps/` and `/docs/` paths resolve as shown.


## Blog
The site now includes `/blog/` plus migrated/updated legacy topics and new app-focused articles targeting practical Shopify, accessibility, event calendar, gift card, audio, SEO and AEO-style question queries.
