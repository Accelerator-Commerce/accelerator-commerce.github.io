Does Your Gift Card Balance Checker Only See Its Own Cards?

Short answer: If your store issues gift cards from more than one source — Shopify's own native gift cards plus a returns app, a loyalty platform, or a separately installed balance-check app — most balance checkers only look up the cards issued through their own system. There's no built-in Shopify feature that consolidates balances across sources, and the cleanest fix is standardizing on Shopify's own native gift card system and pointing every checker at that one source of truth.

A real merchant hit this exact wall

A merchant asked plainly in the Shopify Community for "a page to check balance of ALL gift certificates, from apps and Shopify" — explaining that gift cards issued manually through Shopify and through separate apps couldn't all be looked up in one place, because each app's balance checker only sees the cards it issued itself. The thread named the specific problem: a store using Shopify's native gift cards alongside cards from a returns app and a loyalty platform ended up with three disconnected balance systems and no single page that answered "how much is left on this card" regardless of where it came from.

Why this happens

Every gift card app that issues its own cards — rather than reading Shopify's native gift card records — keeps its own balance ledger. A returns app that issues store-credit-style gift cards for exchanges, a loyalty platform that issues reward gift cards, and Shopify's own native gift card system are three separate databases that don't talk to each other. A balance-check page built by any one of them can only query its own records. There's no Shopify-level API that merges balances across issuing sources, because there's no Shopify-level concept that ties them together in the first place — each app's gift cards are, technically, a different kind of object.

What actually solves it (and what doesn't)

  • Standardize on one issuing source. The most durable fix isn't a smarter balance checker — it's reducing the number of places gift cards get issued from in the first place. If returns, promotions, and purchased gift cards can all route through Shopify's own native gift card system instead of a mix of app-specific ledgers, one balance checker pointed at Shopify's records covers everything.
  • A checker built on Shopify's native gift cards already covers every issuing path that uses them. Whether a native Shopify gift card was purchased at checkout, issued manually by staff, or generated by an app that creates real Shopify gift cards (rather than its own separate credit object), a balance checker built against Shopify's own gift card records sees all of it — because it's reading the same underlying data, not a second parallel ledger.
  • A custom-built consolidation page is possible but expensive to maintain. The merchant in the thread above ended up commissioning custom developer work to query multiple sources and merge the results. That works, but it's bespoke, breaks whenever any one app changes its API, and isn't something most stores can justify building and maintaining themselves.

The question to ask before adding another gift card source

Before installing an app specifically because it issues its own gift cards or store credit, check whether it can instead work with Shopify's native gift cards. An app that reads and writes Shopify's own gift card records — rather than maintaining a separate balance system — keeps every card checkable from one place. An app that issues its own proprietary credit object is adding a second ledger a customer (and a support agent) will eventually have to keep straight from the first.

Where Gift Check Pro fits

Gift Check Pro checks the balance of Shopify's own native gift cards — the ones issued at checkout, by staff in the admin, or by any app that writes to Shopify's real gift card records — from one storefront page and one POS lookup. It doesn't solve the problem of a store deliberately running two or three unrelated credit systems side by side, but it does mean that every native Shopify gift card, regardless of which flow issued it, shows up in the same place.

Frequently asked questions

Is there a native Shopify feature that checks balances across multiple gift card apps?

No. Shopify has no built-in way to merge balance lookups across separate apps' gift card systems. Each app that issues its own cards keeps its own ledger.

Will switching everything to Shopify's native gift cards fix this?

In most cases, yes. If every issuing path — purchase, staff-issued, promotional, returns-driven — writes to Shopify's own gift card records rather than an app-specific credit object, one balance checker built against those records covers all of it.

What if I already have gift cards issued across multiple systems?

A one-time migration (several merchants use bulk import tools like Matrixify) can bring existing balances into Shopify's native gift card system going forward, even if it can't retroactively merge every historical ledger automatically.
