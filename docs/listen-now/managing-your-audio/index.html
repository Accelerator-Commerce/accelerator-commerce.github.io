Everything you upload lives in the Library. From there you can preview tracks, see where each one is playing, and make changes.

Track Details

Click any track to open its Track Details page. Here you can:

  • See stats — plays, completion rate, and where in the track people tend to stop listening (Starter and Pro plans)
  • See where it's assigned — every page or location currently using this track
  • Assign or unassign it to a page
  • Create or edit a clip — trim the track down to a shorter preview
  • Rename or delete the track

One track per spot

Each location (a specific page, or "site wide") can only play one track at a time. If you assign a new track somewhere that already has one, the new track replaces the old one — it doesn't add a second track or create a playlist automatically.

Playlists

Want more than one track in a spot? Create a Playlist (Library > Playlists) to group several tracks together, then assign the whole playlist to a page instead of a single track.

A note on product pages

Right now, individual audio tracks can't be assigned to product pages directly — but the text-to-speech widget does support product pages. See Text-to-Speech.
