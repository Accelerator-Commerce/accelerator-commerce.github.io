Need to update details on a lot of tracks at once? Use Library > Bulk Edit.

  1. Search for and select the tracks you want to change.
  2. Edit their details together instead of opening each one individually.
  3. Save to apply the changes to every selected track.
Free plan: up to 3 tracks per batch.
Starter and Pro plans: no practical batch limit.
