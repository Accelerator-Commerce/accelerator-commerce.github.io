How to Display a Recurring Weekly Class or Event Schedule on Shopify

Quick answer: Don't enter a repeating class or open-hours slot as dozens of separate one-off events. Set it up as a single recurring event with a repeat rule (weekly, on specific weekdays, with an end date or "until cancelled"), let your calendar app generate the individual occurrences automatically, and make sure the display groups them so a shopper sees "Every Tuesday, 6pm" instead of fifty identical-looking listings.

Recurring events are now a baseline feature, not a differentiator

If you sell recurring classes, host weekly open studio hours, or run a pop-up on the same day every week, you've probably searched for how to show that on your Shopify store without re-creating the same event by hand every seven days. The good news is that repeat scheduling is now table-stakes functionality across the entire event calendar app category — the real question isn't whether an app supports it, but how to set it up so it actually reads well to a shopper.

Set the event up as one recurring rule, not many one-off entries

The most common mistake is treating a recurring class the same way you'd treat a single concert date: creating a new event entry for every occurrence. That works for a week or two, then becomes unmanageable — every time you change the time, cancel a week for a holiday, or update the description, you have to edit every future entry individually.

  • Create the event once. Set the title, description, and location as you normally would for any event.
  • Add a repeat rule. Choose the frequency (weekly is most common for classes), the day or days of the week it happens, and a time.
  • Set an end condition. Pick a fixed end date for a seasonal class, or leave it open-ended ("repeats until cancelled") for something ongoing like weekly open studio hours.
  • Let the app generate the occurrences. A good calendar app expands the rule into individual dates automatically, so you never touch a second entry unless a specific week needs an exception.

Handle exceptions without breaking the whole series

Recurring schedules almost always need occasional exceptions — a holiday closure, a one-off time change, a cancelled week. The pattern that holds up:

  • Cancel or edit a single occurrence rather than deleting and recreating the whole recurring series. The series should keep running on its normal schedule afterward.
  • Mark cancelled dates clearly on the display rather than silently removing them — a shopper who already had that Tuesday circled should see it's cancelled, not just find it missing.
  • Avoid stacking multiple overlapping recurring rules for the same class (for example, a "regular schedule" rule and a separate "holiday schedule" rule covering the same dates) — that's the fastest way to end up with duplicate or conflicting listings.

Display it as a schedule, not a wall of duplicate dates

Even with the underlying data set up correctly, a recurring class can still look wrong on the front end if every occurrence renders as its own separate tile. The better pattern groups same-time recurring events into a single, compact schedule line — "Yoga Flow · Every Tuesday, 6:00pm" — with the full list of individual dates available on click or in a details view, rather than fifty near-identical cards filling the calendar page.

Frequently asked questions

Can I have a recurring event that only happens on some weeks, not every week?

Most repeat rules support skipping specific dates as exceptions (holidays, planned closures) without ending the whole series — set the normal weekly rule, then cancel the individual weeks that don't apply rather than building a more complex custom pattern.

What happens to past occurrences when I edit a recurring event?

A well-built recurring event only affects future occurrences when you edit the series — past dates that already happened stay as they were, which matters if you're using the calendar as any kind of record of what actually ran.

Should I use a recurring display calendar or a booking app for weekly classes?

If shoppers just need to see when a class happens (and buy a spot as a product), a display calendar with recurring events is usually enough and far simpler to run. If you need seat limits, individual reservations, or per-session capacity tracking, a dedicated booking app is a better fit — see the comparison guide linked above for the full breakdown.
