Want to embed content from SoundCloud, YouTube, Bandsintown, or another site? You can add any embed code directly through the Theme Editor.

  1. Open the Listen Now! app block or embed section in your Theme Editor.
  2. Scroll past the Advanced Configuration section to the Embed iframes field.
  3. Paste in your embed code.
  4. Save — the embed shows up right away.

This works on the site-wide widget, homepage blocks, individual pages, blog posts, and product pages.
