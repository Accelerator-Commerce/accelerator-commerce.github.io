You can add audio to Listen Now! in a few ways:

  • Upload a file — drag and drop or browse for a file (MP3, WAV, AAC, OGG, or M4A). Up to 20 MB through most upload screens, or up to 50 MB in the Upload Track wizard.
  • Paste a URL — if your audio already lives somewhere online, paste the link in the Upload Track wizard and we'll fetch it for you.
  • Use something already in Shopify — if you've uploaded audio through Shopify's own Content > Files section, you can pick it from there too.

Everything you upload is stored securely with Shopify, and you can see or manage it any time under Content > Files in Shopify Admin.

Before you upload

Make sure you have the rights to use the audio — music, voice recordings, sound effects, all of it. Listen Now! isn't responsible for content you upload without permission to use it.

Need a different file format?

Email us at help@acceleratorcommerce.com and let us know what you need.
