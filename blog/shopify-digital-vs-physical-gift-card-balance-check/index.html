Digital vs. Physical Shopify Gift Cards: Where to Check the Balance

Quick answer: A digital Shopify gift card is delivered by email or SMS with a code and a hosted balance page link, so checking its balance starts with that original message. A physical gift card is activated at the point of sale and identified by a barcode or QR code, so checking its balance means scanning or entering that code — either at checkout, at POS, or through a dedicated balance-check page. Both work anywhere the store accepts gift cards; they just start from different places when you're trying to look up the balance.

Why this trips people up

Digital and physical gift cards on Shopify are the same underlying system — same balance, same redemption at checkout — but they're issued and delivered through different mechanics, and those mechanics are exactly what determine where you go to check the balance. Someone holding a physical card who tries to look for an email confirmation, or someone holding a digital code who goes looking for a barcode to scan, will come up empty even though nothing is actually wrong with the card itself.

If you have a digital gift card

  • Start with the original delivery email or text. Shopify's digital gift cards are delivered with a unique code and typically a link to a hosted "view gift card" balance page — that page shows the current balance directly.
  • No physical object to scan. The code itself, not a barcode, is what gets entered at checkout or into a balance-checking tool.
  • Lost the email? Check spam/promotions folders first, then the order confirmation from the original purchase, which usually references the same code.

If you have a physical gift card

  • Physical cards are activated through POS when purchased in person, whether ordered through Shopify Hardware or a third-party card printer.
  • The barcode or QR code on the card is the identifier that gets scanned at checkout — the same code can typically be entered manually if a scanner isn't available.
  • Balance checking doesn't require a purchase. A dedicated balance-check tool lets a shopper or staff member confirm the remaining balance by scanning or entering the code, without needing to start a transaction just to see the number.
  • Pre-existing physical cards — ones acquired outside a normal Shopify checkout — sometimes need to be manually entered into the system before their balance shows up correctly, which is a separate setup step worth ruling out if a card scans as invalid.

The practical difference in one line

Digital: check your email or text first. Physical: check the code printed or embossed on the card. Everything else — where that code ultimately gets entered to reveal the balance — works the same way once you have it in hand.

Where Gift Check Pro fits

Gift Check Pro handles both card types through the same balance-check flow, so shoppers and staff don't need to know in advance which lookup path applies — enter or scan the code, digital or physical, and the current balance shows up the same way either time. That single entry point is the part that actually matters once you know which kind of code you're starting with.

Frequently asked questions

Do digital and physical Shopify gift cards draw from the same balance system?

Yes — both are tracked through the same underlying gift card balance system on Shopify. The difference is purely in how each type is delivered and identified, not in how the balance itself is stored or redeemed.

Can a physical gift card's balance be checked without a barcode scanner?

Yes — the code printed on a physical card can typically be entered manually wherever a balance check accepts a gift card code, which is useful for phone-based support or a balance-check page that doesn't have scanning hardware.

What if I have a physical card that was never scanned into the system?

A pre-existing physical card acquired outside a standard Shopify checkout sometimes needs to be manually added to the gift card system before it will scan correctly — if a card shows as invalid despite looking legitimate, that setup step is worth checking with the merchant before assuming the card has no balance.
